
##BLOG APPLICATION

This project is divided into five different sections fully explained below.

#SECTION ONE: Project Overview.
This project is a simple blog application developed using the Django web framework. The application is designed for general users, who want to read and share blog posts on various topics.
This blog allows users to view posts published by different authors, while administrators can manage blog content through an admin dashboard. The goal of this project is to demonstrate an understanding of backend web development concepts such as models, views, templates, and database management using Django.

#SECTION TWO: Problem Statement.
Many individuals want a simple and easy-to-use platform where they can share information, ideas, or opinions with a wide audience. However, existing blogging platforms can be complex or require technical knowledge to manage.
This project aims to solve this problem by creating a simple blog application that is easy to manage and accessible to general users.

#SECTION THREE: Project Objectives.
The main objectives of this project are as follows;
Build a functional blog application using Django
Allow administrators to create, edit, and delete blog posts
Display blog posts in a user-friendly interface for general users
Understand Django’s Model-View-Template (MVT) architecture
Gain experience working with databases and migrations.

#SECTION FOUR: Project Features.
The blog application includes the following features:
 View a list of published blog posts
 Read individual blog posts
Admin panel for managing blog content
Automatic recording of post publication date
User association for each blog post
